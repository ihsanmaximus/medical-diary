# Medical Diary

Personal Health Tracker & Medical Diary — mobile-first PWA.

## Stack
- React + Vite
- Responsive rose-themed UI
- Installable PWA foundation

## Development
```bash
npm install
npm run dev
```

> Prototype stage: data is currently stored locally in the browser. Do not use this prototype as the sole storage for important medical records. Supabase integration and authentication will be added in a later stage.
